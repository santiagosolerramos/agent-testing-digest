# Agent Eval Digest — 2026-05-19

## TL;DR
Today's items highlight practical advances in synthetic persona simulation for UX and product testing plus multi-turn conversation metrics and function-calling evaluation. These directly address Connectly's open questions around building realistic personas that surface edge cases and measuring tool use plus task completion in multi-turn WhatsApp flows. The strongest signal is that teams are moving from generic LLM judges to goal-oriented, end-to-end metrics that align with our Test Framework.

## 🎯 Top 3 para Connectly

### 1. Synthetic Users Explained: Top 7 AI User Research Tools
**Por qué importa para Connectly:** Brox.ai’s approach of generating synthetic users that navigate interfaces and surface usability friction maps almost 1:1 to the simulated personas we already run against our WhatsApp agents in Test Framework.  
**Acción concreta:** Add a “navigation friction” trait to our persona YAML so tests can flag when the agent fails to guide users through catalog browsing or checkout flows.

### 2. No, not supported
**Por qué importa para Connectly:** The conversation-completeness metric (LLM-as-judge) explicitly measures whether a multi-turn agent satisfies the inferred user goal—exactly the evaluation gap we have when checking order cancellation or cart recovery success.  
**Acción concreta:** Prototype this metric as an additional evaluation step in Test Framework after each simulated dialogue ends.

### 3. What is AI Agent Evaluation? | IBM
**Por qué importa para Connectly:** The post calls out task-completion rate and function-calling accuracy as core metrics; both are missing or manual in our current regression suite.  
**Acción concreta:** Instrument Test Framework to log every tool call and compute task-completion rate automatically on mock orders.

### No, not supported
*Source: tavily | 2026-05-19*

Confident AI introduces a multi-turn “conversation completeness” metric that first infers the user’s goal and then judges whether it was satisfied across the full dialogue. This is a stronger signal than single-turn checks and would directly improve regression detection when we update prompts or models in our WhatsApp agents.
