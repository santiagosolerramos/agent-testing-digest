# Agent Eval Digest — 2026-11-06

## TL;DR
Sierra launched Agent Studio with built-in conversation simulation and regression suites, directly mirroring Connectly’s Test Framework needs. A new academic tool (Sensei) demonstrates scalable synthetic conversation generation for end-to-end testing of any REST-accessible agent. Short-form industry definitions of AI agent regression testing reinforce the value of state-checking after every prompt or tool change.

## 🎯 Top 3 para Connectly

### 1. [Agent Studio | Sierra](https://sierra.ai/product/agent-studio)
**Por qué importa para Connectly:** Sierra’s regression testing and AI-driven conversation simulation directly compete with our internal Test Framework and highlight how a leading WhatsApp-scale competitor operationalizes persona-based evals.  
**Acción concreta:** Add Sierra’s “defined outcomes” + regression suite pattern to our persona YAML so every new prompt change automatically runs the same multi-turn scenarios.

### 2. [Automated End-to-End Testing for Conversational Agents](https://miso.es/pubs/JSS_SENSEI.pdf)
**Por qué importa para Connectly:** Sensei generates full conversations programmatically and evaluates any agent reachable via REST, exactly the setup needed to expand our mock-data deterministic tests beyond happy paths.  
**Acción concreta:** Prototype a thin wrapper that feeds Sensei-style synthetic dialogues into Test Framework and measure how many additional edge cases it surfaces versus our current personas.

### 3. [What Is AI Agent Regression Testing?](https://agentiqa.com/en/glossary/ai-agent-regression-testing)
**Por qué importa para Connectly:** The definition emphasizes checking end-state changes in external systems after every model or tool update—directly addressing our open question on catching subtle regressions.  
**Acción concreta:** Extend our current evaluation step to assert on tool-call side effects (order status, cart updates) instead of only final text.
