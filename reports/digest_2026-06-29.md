# Agent Eval Digest — 2026-06-29

## TL;DR
Meta launched its Business Agent globally on WhatsApp (and Instagram DMs), with built-in support for product recommendations, appointment booking, lead qualification, and seamless human handoff. The agent is trained directly on a business’s website and catalog, and it leverages native WhatsApp UI elements for quick replies and full-screen flows. This is the strongest direct competitor signal yet for Connectly’s multi-turn WhatsApp agents.

## 🎯 Top 3 para Connectly

### 1. [Meta's AI agent for WhatsApp Business is now available globally](https://techcrunch.com/2026/06/03/metas-ai-agent-for-whatsapp-business-is-now-available-globally)
**Por qué importa para Connectly:** Meta’s agent explicitly supports the same core flows Connectly targets (FAQ, product recs, appointments, lead qualification, and handoff), making it the clearest benchmark for our Test Framework personas.  
**Acción concreta:** Add a new “Meta parity” test suite in Test Framework that runs the same persona objectives against both our agent and a simulated Meta agent to quantify gaps in multi-turn success rate and handoff quality.

### 2. [The Architecture of Meta Business Agent on WhatsApp](https://www.youtube.com/watch?v=I8-rSW3UALs)
**Por qué importa para Connectly:** The demo shows Meta blending conversational messages with native full-screen experiences to reduce friction—exactly the kind of edge case our current personas rarely stress-test.  
**Acción concreta:** Extend the persona simulator to include “UI-aware” behaviors (e.g., accepting quick-reply buttons or opening product catalogs) so we can measure whether our agent maintains context across mixed conversational/full-screen paths.

### 3. [Meta Business Agent on WhatsApp](https://whatsappbusiness.com/products/business-app-ai-agent)
**Por qué importa para Connectly:** The onboarding flow shows Meta agents are trained purely from website + catalog data with no custom prompt engineering, highlighting a potential simplicity advantage over our current persona and mock-data setup.  
**Acción concreta:** Prototype an automated “catalog sync” eval in Test Framework that checks whether our agent can match Meta’s zero-config product grounding accuracy on the same mock catalogs.
