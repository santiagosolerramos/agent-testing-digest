# Agent Eval Digest — 2026-07-16

## TL;DR
The most actionable items today are a practical WhatsApp AI agents guide with concrete resolution-rate benchmarks, Agnost AI’s feedback extraction tool for post-conversation analysis, and OpenAI’s GPT-Red automated red-teaming system. These directly inform how Connectly can tighten its Test Framework personas, add conversation-level outcome metrics, and harden agents against prompt-injection failures before they reach production WhatsApp traffic.

## 🎯 Top 3 para Connectly

### 1. [Ultimate Guide to WhatsApp AI Agents](https://www.interakt.shop/whatsapp-ai-agents/guide)
**Por qué importa para Connectly:** Provides explicit benchmarks (60–90 % auto-resolution, 2–3× lead conversion) that map straight onto the success criteria already used in our Test Framework evaluations.
**Acción concreta:** Add the resolution-rate and escalation metrics as new evaluation dimensions in the persona YAML so every simulated multi-turn run reports these numbers automatically.

### 2. [Launch HN: Agnost AI (YC S26) – Extract user feedback from agent conversations](https://agnost.ai)
**Por qué importa para Connectly:** Automates extraction of failure signals and user intent from real agent logs—exactly the missing piece for turning Test Framework runs into a living regression suite.
**Acción concreta:** Pilot Agnost on the last 30 days of Test Framework transcripts to surface which personas most often trigger incorrect tool calls or escalations.

### 3. [GPT-Red: Unlocking Self-Improvement for Robustness](https://openai.com/index/unlocking-self-improvement-gpt-red)
**Por qué importa para Connectly:** Demonstrates an automated self-play loop that discovers prompt-injection and robustness failures without manual red-team scripts—directly applicable to hardening our multi-language WhatsApp agents.
**Acción concreta:** Run a 48-hour GPT-Red-style self-play experiment against the current agent prompt using our existing mock catalog to quantify injection surface area.
