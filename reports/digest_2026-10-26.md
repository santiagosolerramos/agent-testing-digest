# Agent Eval Digest — 2026-10-26

## TL;DR
Anthropic published practical guidance on evaluating multi-turn conversational agents that use tools and maintain state — directly relevant to Connectly's Test Framework. Two additional pieces surfaced on agent evaluation frameworks and regression testing tooling, offering concrete ideas for scaling deterministic tests with simulated personas. These items collectively address open questions around regression suites, tool-use evals, and catching subtle prompt changes.

## 🎯 Top 3 para Connectly

### 1. [Demystifying evals for AI agents](https://www.anthropic.com/research/demystifying-evals-for-ai-agents)
**Por qué importa para Connectly:** Anthropic's breakdown of conversational agent evals (state, tool calls, action quality) maps almost 1:1 to the multi-turn goal-oriented tests our personas run against WhatsApp agents.  
**Acción concreta:** Add a new "state + tool" evaluation dimension to the Test Framework YAML so every persona run scores both final outcome and intermediate tool correctness.

### 2. [Agent Regression Testing](https://topai.tools/s/agent-regression-testing)
**Por qué importa para Connectly:** The post surfaces self-healing, no-code regression tools that could reduce false positives when we update prompts or models in production.  
**Acción concreta:** Pilot one of the listed AI-driven visual/end-to-end testing tools against our current regression suite to see if it catches prompt-induced breaks faster than manual persona review.

### 3. [AI Agent Evaluation Frameworks Compared (2026)](https://www.techment.com/blogs/ai-agent-evaluation-frameworks)
**Por qué importa para Connectly:** A 2026 comparison of agent eval platforms could surface libraries that already solve persona simulation + deterministic mock-data testing at scale.  
**Acción concreta:** Review the top 2–3 frameworks mentioned and benchmark one against our internal Test Framework on a small set of WhatsApp order-recovery test cases.
