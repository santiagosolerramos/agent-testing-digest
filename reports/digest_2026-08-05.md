# Agent Eval Digest — 2026-08-05

## TL;DR
Synthetic data generation and full-trajectory agent evaluation dominate today's releases. Two practical tools (Evidently and QASkills) plus a production-focused framework from Algolia directly address Connectly's open questions on scaling evals, writing realistic personas, and testing tool use without drowning in false positives.

## 🎯 Top 3 para Connectly

### 1. [AI agent evaluation: frameworks, metrics & testing strategies](https://www.algolia.com/blog/ai/ai-agent-evaluation-frameworks-metrics-testing-strategies)
**Por qué importa para Connectly:** Emphasizes evaluating full execution trajectories (tool calls, reasoning order) rather than final outputs — exactly the gap in our current Test Framework evaluations.
**Acción concreta:** Extend our evaluation step to score intermediate tool calls and execution order using the trajectory metrics described.

### 2. [Synthetic Data for LLM and RAG Testing: Practical Guide | QASkills.sh](https://qaskills.sh/blog/synthetic-data-llm-rag-testing-2026)
**Por qué importa para Connectly:** Provides concrete methods for generating realistic synthetic users that preserve multi-turn quirks and goal-oriented behavior, directly applicable to our persona definitions.
**Acción concreta:** Prototype a persona generator that follows the guide's quality-control steps and feed the outputs into Test Framework YAML.

### 3. [Evidently 0.7.11: open-source synthetic data generation for LLM systems](https://www.evidentlyai.com/blog/synthetic-data-generator-python)
**Por qué importa para Connectly:** Offers open-source generation of adversarial and edge-case inputs that can be turned into synthetic personas for regression testing.
**Acción concreta:** Integrate Evidently's generator into our mock-data pipeline to auto-create prompt-injection and rare-intent test cases.
