# Agent Eval Digest — 2026-10-22

## TL;DR
Two high-signal items landed today: a reproducible agent testing framework with deterministic tool stubs and trace ledgers (directly relevant to Test Framework), and a WhatsApp-specific testing checklist that highlights real production failure modes like template windows and handoff verification. A third paper on synthetic user limitations provides concrete guidance for improving persona quality.

## 🎯 Top 3 para Connectly

### 1. [AI Agent Evaluation Framework (2026): Reproducible Agent Testing](https://labs.lamatic.ai/p/ai-agent-evaluation-framework-2026)
**Por qué importa para Connectly:** Matches our Test Framework structure almost exactly with scenario fixtures, deterministic tool stubs, and tool-call assertions — the missing pieces for scaling beyond happy-path tests.
**Acción concreta:** Map our current persona YAML to their scenario-fixture format and add trace-ledger assertions for tool calls and handoffs.

### 2. [WhatsApp AI Agent Testing: A 5-Step Checklist](https://ask4lead.com/whatsapp-ai-agent-testing)
**Por qué importa para Connectly:** Directly addresses WhatsApp-specific constraints (24h window, template approval, webhook reliability) that our agents hit in production.
**Acción concreta:** Add a dedicated WhatsApp test mode to Test Framework that enforces template and handoff verification instead of generic conversation checks.

### 3. [When Synthetic Users Fail: A Cross-Domain Benchmark of LLM-Simulated Human Survey Responses](https://ubos.tech/when-synthetic-users-fail-a-cross-domain-benchmark-of-llm-simulated-human-survey-responses)
**Por qué importa para Connectly:** Shows exactly where persona simulation breaks (domain shift, over-consistency, missing edge behaviors), which is our core open question on writing personas that find real edge cases.
**Acción concreta:** Run a small internal benchmark of our current personas against their failure modes and add diversity constraints to the persona generator.
