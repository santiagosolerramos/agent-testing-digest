# Agent Eval Digest — 2026-05-30

## TL;DR
Two high-signal pieces landed today on simulation-based conversational evaluation (Cekura) and comparative regression testing for multi-turn agents. Both map directly to Connectly’s Test Framework gaps around persona-driven edge cases, tool-argument drift, and catching regressions after prompt/model updates. The rest of the feed is either too generic or off-topic for WhatsApp-scale goal-oriented agents.

## 🎯 Top 3 para Connectly

### 1. [5 Best Tools to Evaluate Conversational AI Agents (Tested in 2026)](https://www.cekura.ai/discover/best-conversational-ai-evaluation-tools)
**Por qué importa para Connectly:** Cekura’s simulation-first, multi-turn scenario engine is the closest public analog to our persona + objective + evaluation loop and explicitly targets branching conversations before deployment.
**Acción concreta:** Run a side-by-side bake-off of Cekura against our internal Test Framework on 20 existing personas to see whether their structured scenario format surfaces new failure modes we currently miss.

### 2. [Agent Regression Testing: 6 Approaches Compared – Evalvista](https://evalvista.com/agent-regression-testing-approaches-compared)
**Por qué importa para Connectly:** Explicitly calls out the exact regression classes we worry about (multi-turn drift after tool calls, subtle argument errors, policy vs. task-completion trade-offs, token economics) and compares detection methods.
**Acción concreta:** Adopt their comparative “before/after” reporting template for the next prompt or model change in CI so we stop relying on simple pass/fail.

### 3. [Even (very) noisy LLM evaluators are useful for improving AI agents](https://www.tensorzero.com/blog/even-very-noisy-llm-evaluators-are-useful-for-improving-ai-agents/)
**Por qué importa para Connectly:** Shows that even low-agreement LLM judges still provide useful directional signal for agent improvement loops—relevant for scaling our evaluation step without drowning in false positives.
**Acción concreta:** Experiment with adding a cheap noisy LLM judge on top of our current deterministic checks to surface candidate regressions before human review.
