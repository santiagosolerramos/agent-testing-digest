## TL;DR
Sierra published new positioning on their customer-facing agent (direct competitor). ## 🎯 Top 3 para Connectly

### 1. [Meet your agent | Sierra](https://sierra.ai/product/meet-your-ai-agent)
**Por qué importa para Connectly:** Sierra is explicitly positioning its agent as a replacement for IVR with tone/empathy detection and multi-channel support, directly overlapping Connectly’s WhatsApp use case.
**Acción concreta:** Add Sierra-style tone-shift test cases to the Test Framework persona suite to check whether our agents detect frustration and escalate appropriately.

### 2. [How to Build an AI Agent Evaluation Testing Framework](https://spiderhunts.com/blog/ai-agent-evaluation-testing-framework)
**Por qué importa para Connectly:** Describes exactly the stack we need: golden datasets, LLM-as-judge, and CI gating for multi-turn goal-oriented agents.
**Acción concreta:** Extract the YAML test-case format and LLM-judge rubric from the guide and prototype it inside Test Framework this sprint.

### 3. [AI agent evaluation bench for ERP, CRM | SOBERAN](https://www.soberan.co/news/evaluation-bench-ai-agents-erp-crm-contact-center-automation)
**Por qué importa para Connectly:** Provides a ready-made bench specifically for WhatsApp order-status, returns, warranty, and escalation scenarios using mock data.
**Acción concreta:** Import the WhatsApp test scenarios into Test Framework and run them against our current prompt to measure baseline pass rate.
