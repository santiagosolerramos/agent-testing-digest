# Agent Eval Digest — 2026-09-12

## TL;DR
τ-bench introduces a concrete multi-turn benchmark for retail/airline agents that enforces policy adherence and tool use—directly relevant to Connectly’s Test Framework. Two pieces on LLM-driven synthetic users and multi-turn eval practices provide practical patterns for scaling persona-based testing without exploding false positives.

## 🎯 Top 3 para Connectly

### 1. [Agent Evaluation: A Detailed Guide - Deep (Learning) Focus](https://cameronrwolfe.substack.com/p/agent-evals)
**Por qué importa para Connectly:** τ-bench’s retail domain (orders, policies, tool calls) maps almost 1:1 to Connectly’s WhatsApp order-resolution and cart-recovery flows, including the exact failure modes our current personas still miss.
**Acción concreta:** Add a τ-bench-style retail domain to the Test Framework YAML so every persona run also checks policy adherence and correct tool invocation.

### 2. [LLM-Powered Synthetic User Simulation — Lacuna](https://lacuna.tiptreesystems.com/direction/llm-powered-synthetic-user-simulation/txn_57d794f28fd44c7d9ed338869851a6e4)
**Por qué importa para Connectly:** The post formalizes the exact technique we already use—prompting LLMs as goal-driven personas—but adds concrete advice on sandbox scale and failure-mode coverage.
**Acción concreta:** Run an internal experiment generating 500 synthetic conversations per persona using the Lacuna prompting pattern and measure how many new edge cases surface versus our current set.

### 3. [Evaluating Multi-Turn Conversational AI: Best Practices for…](https://www.promptlayer.com/blog/best-practi-to-evaluate-back-and-forth-conversational-ai-in-promptlayer)
**Por qué importa para Connectly:** Highlights the compounding-variables problem that currently produces noisy signals in our regression suite after prompt changes.
**Acción concreta:** Adopt the suggested “conversation-level metric + per-turn annotation” split so we can isolate whether a regression is in the first turn or later policy enforcement.

## Top Findings

### Evaluation Frameworks & Benchmarks

### [Agent Evaluation: A Detailed Guide - Deep (Learning) Focus](https://cameronrwolfe.substack.com/p/agent-evals)
*Source: tavily | 2026-09-12*

τ-bench runs fully dynamic, multi-turn conversations in retail and airline domains where the agent must both resolve user intent and strictly follow written policies while using tools. The benchmark ships with deterministic mock environments and clear success criteria (policy compliance + correct tool calls + goal completion). This is the closest public artifact to the exact evaluation surface Connectly needs for its order and cart agents.

### Multi-Turn & Dialogue Evaluation
