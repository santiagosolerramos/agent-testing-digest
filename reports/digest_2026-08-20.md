**Acción concreta:** Add an "agent-security" tag to our eval taxonomy and schedule a quarterly review of whether our handoff and tool-use tests need explicit adversarial checks.

### Synthetic User & Persona Simulation
### Evaluating Large Language Models as Generative User ... (https://aclanthology.org/2024.naacl-long.83.pdf)
*Source: tavily | 2026-08-20*

The paper surveys recent work on using LLMs to generate synthetic users for conversational search, HCI, and social-science experiments. For Connectly this is immediately actionable: the cited methods can be adapted to produce personas that reliably trigger edge cases in multi-turn WhatsApp flows instead of happy-path conversations.

*Source: hackernews | 2026-08-19*

OneCLI is an open-source harness that runs agents inside a sandbox with controllable tools and state, aimed at team-scale testing. If the project matures, it could replace ad-hoc scripts in our Test Framework and reduce flakiness when we update prompts or models.
