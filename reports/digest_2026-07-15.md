# Agent Eval Digest — 2026-07-15

## TL;DR
Three new practical resources on agent regression testing appeared today, directly addressing how teams prevent prompt/model changes from breaking multi-turn behavior. These map cleanly to Connectly’s open questions around regression suites and catching subtle degradations in the Test Framework.

## 🎯 Top 3 para Connectly

### 1. [Agent Regression Testing: Manual vs Automated vs Eval Harness](https://evalvista.com/agent-regression-testing-comparison-manual-automated-harness)
**Por qué importa para Connectly:** Compares exactly the three approaches we currently debate for our Test Framework (manual review, scripted tests, and harness-driven eval).  
**Acción concreta:** Map the “eval harness” column against our current YAML persona runner and decide whether to adopt the harness pattern for CI.

### 2. [Agent Regression Testing Checklist for AI Agent Teams](https://evalvista.com/agent-regression-testing-checklist)
**Por qué importa para Connectly:** Provides a ready-made checklist that explicitly covers tool-use correctness and multi-turn goal completion—two dimensions we already score but lack a systematic list for.  
**Acción concreta:** Turn the checklist into a pre-merge template that every prompt change must pass before it reaches the Test Framework.

### 3. [Regression Testing (Agent) – Prefactor Glossary](https://prefactor.tech/glossary/regression-testing-agent)
**Por qué importa para Connectly:** Defines the minimal contract we need: “changes to model, prompt, tool, or policy must not degrade previously passing test cases.”  
**Acción concreta:** Add this exact definition to our internal docs and use it as the success criterion in the Test Framework’s final evaluation step.
