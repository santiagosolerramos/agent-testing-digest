# Agent Eval Digest — 2026-09-21

## TL;DR
Braintrust's regression testing guidance directly addresses the exact pain point in our Test Framework: prompt or model changes that silently degrade specific user categories without triggering obvious failures. Two lower-relevance releases (jevals and a synthetic data benchmark) touch on eval tooling and persona data generation but lack immediate production applicability.

## 🎯 Top 3 para Connectly

### 1. [Regression testing definition - Braintrust](https://www.braintrust.dev/encyclopedia/regression-testing)
**Por qué importa para Connectly:** It explicitly calls out the exact failure mode we see when updating prompts—average quality improves while performance drops on specific persona categories—and recommends a fixed eval suite, which maps 1:1 to our multi-turn persona tests.
**Acción concreta:** Add a "regression category" field to every persona YAML so we can automatically surface category-specific score drops after any prompt or model change.

### 2. [Show HN: jevals – replacing LLM judges with typed Jev decisions](https://github.com/openlayer-ai/jevals)
**Por qué importa para Connectly:** Offers a typed alternative to LLM-as-judge for deterministic pass/fail decisions, which could reduce false positives in our current evaluation step.
**Acción concreta:** Prototype replacing the final LLM judge in Test Framework with jevals on 20 existing test cases to measure agreement and latency.

### 3. [RWS's TrainAI LLM Benchmarking Study Ranks Claude Sonnet, GPT and Gemini Pro as Leaders in Synthetic Data Generation](https://finance.yahoo.com/news/rwss-trainai-llm-benchmarking-study-080000382.html)
**Por qué importa para Connectly:** Benchmarks LLMs on synthetic data generation across languages, relevant because we rely on mock data and synthetic personas for deterministic tests.
**Acción concreta:** Run a small internal test generating 50 Spanish and Portuguese personas with the top-ranked models and compare quality against our current manual mock data.

## Top Findings

### Regression Testing & CI/CD for Agents

### [Regression testing definition - Braintrust](https://www.braintrust.dev/encyclopedia/regression-testing)
*Source: tavily | 2026-09-21*

Braintrust highlights that agent regressions are often silent (tone shifts, category-specific degradation) and can only be caught with a fixed, reusable eval suite rather than ad-hoc checks. This directly validates our current Test Framework approach and explains why we need category-level tracking when we swap models or prompts. The piece is short but actionable for any team running multi-turn goal-oriented agents.

**Tags:** `regression` `evaluation` `testing`
**Prioridad:** 🔴 Alta

### Evaluation Frameworks & Benchmarks

### [Show HN: jevals – replacing LLM judges with typed Jev decisions](https://github.com/openlayer-ai/jevals)
*Source: hackernews | 2026-09-20*

jevals introduces typed decision objects to replace free-form LLM judges, aiming for more reliable and debuggable eval outcomes. While still early, the concept could reduce variance in our persona-based evaluations if integrated as the final checker. Limited discussion and adoption data make it lower priority for now.
