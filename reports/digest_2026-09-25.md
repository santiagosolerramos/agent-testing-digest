## 🎯 Top 3 para Connectly

### 1. [What Is Regression Testing for AI Agents? Definition](https://nhimg.org/glossary/regression-testing-for-ai-agents)
**Por qué importa para Connectly:** Directly addresses how to anchor tool-use patterns, refusals, and approvals when prompts or models change — exactly the regression problem called out in our internal Test Framework.
**Acción concreta:** Add a “regression anchor” section to our persona YAML that lists previously verified tool calls and refusal behaviors to re-check on every prompt update.

### 2. [Prepare a WhatsApp AI agent and handoff · Docs — Bird](https://bird.com/docs/guides/whatsapp/ai-agents)
**Por qué importa para Connectly:** Shows an explicit evaluation loop for ordinary questions, policy exceptions, failed integrations, and human handoff — all core to our WhatsApp agents.
**Acción concreta:** Incorporate Bird’s “rehearse ordinary questions + record task completion” checklist into the final evaluation step of Test Framework runs.

### 3. [What Is Regression Testing for AI Agents? Definition](https://nhimg.org/glossary/regression-testing-for-ai-agents)
**Por qué importa para Connectly:** Reinforces the need to test previously reviewed tool-use patterns after any change, directly relevant to our multi-turn goal-oriented conversations.
**Acción concreta:** Prototype a small regression suite that replays the same simulated personas after each model or prompt deployment and alerts on changed tool-call sequences.
