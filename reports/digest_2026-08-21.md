# Agent Eval Digest — 2026-08-21

## TL;DR
The strongest signals today are practical guides on building evaluation infrastructure for agents, trajectory-based regression testing for tool-calling, and empirical findings that synthetic users produce overly linear behavior compared to real users. These map directly to scaling Test Framework, writing better persona objectives, and catching regressions after prompt/model changes.

## 🎯 Top 3 para Connectly

### 1. [AI Agent Testing: How to Test Tool Calling, Regressions, and Failure Handling](https://www.confident-ai.com/knowledge-base/guides/ai-agent-testing)
**Por qué importa para Connectly:** Directly addresses trajectory assertions and reading real execution traces before writing tests — exactly the gap in our multi-turn persona + evaluation setup.  
**Acción concreta:** Update our Test Framework YAML to require a short “observed trace” section before any new trajectory assertion is added.

### 2. [What is Regression Testing for AI Agents?](https://aide.app/glossary/what-is-regression-testing-for-ai-agents)
**Por qué importa para Connectly:** Gives a crisp definition and workflow for re-running agents against known cases after every change — core to our open question on catching subtle regressions.  
**Acción concreta:** Add a nightly “regression pack” job in Test Framework that runs the top 50 personas against the current prompt/model and fails CI on any outcome change.

### 3. [We Ran an Experiment with Synthetic Users](https://www.userbrain.com/blog/synthetic-users-experiment)
**Por qué importa para Connectly:** Shows that LLM-based synthetic users follow neat paths while real users wander and second-guess — a direct risk for our persona simulation quality.  
**Acción concreta:** Add an explicit “detour injection” instruction to all personas (e.g., “occasionally contradict yourself or ask an irrelevant follow-up”) and measure how often the agent still succeeds.
