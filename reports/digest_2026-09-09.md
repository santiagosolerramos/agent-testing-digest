# Agent Eval Digest — 2026-09-09

## TL;DR
Two new papers directly stress-test LLM-based user simulation in multi-turn and survey settings, exposing systematic failures in demographic fidelity and individual-level accuracy. These findings are immediately relevant to Connectly’s Test Framework personas and the open question of writing personas that surface real edge cases rather than happy paths.

## 🎯 Top 3 para Connectly

### 1. Synthetic Users, Real Differences: an Evaluation Framework for User Simulation in Multi-Turn Conversations | alphaXiv
**Por qué importa para Connectly:** Directly tackles multi-turn persona evaluation—the exact setup used by our Test Framework—making it the highest-signal item today.
**Acción concreta:** Extract the proposed evaluation metrics and add them as new outcome checks in our persona YAML schema.

### 2. When Synthetic Users Fail: A Cross-Domain Benchmark of LLM-Simulated Human Survey Responses
**Por qué importa para Connectly:** Quantifies the exact failure modes (over-reliance on demographics, poor individual prediction) that our current personas risk exhibiting.
**Acción concreta:** Run a small internal audit: replay 50 recent Test Framework runs with demographic-only vs. behavior-trait personas and measure divergence.

### 3. How well do agents use test/verification techniques?
**Por qué importa para Connectly:** Explores whether agents can self-verify tool calls and outcomes—directly applicable to our “correct tool call” and “no hallucination” eval criteria.
**Acción concreta:** Prototype a lightweight self-verification step inside the agent before it returns a final answer and measure impact on false-positive rate in the Test Framework.

## Top Findings

### Synthetic User & Persona Simulation

### Synthetic Users, Real Differences: an Evaluation Framework for User Simulation in Multi-Turn Conversations | alphaXiv
*Source: tavily | 2026-09-09*

Presents a new framework (isle-dev/realsim) for measuring how faithfully synthetic users reproduce real multi-turn behavior. The work focuses on reproducibility and cost at scale—precisely the constraints Connectly faces when running thousands of persona simulations nightly.
**Tags:** `synthetic-data` `persona-simulation` `evaluation`
**Prioridad:** 🔴 Alta

### When Synthetic Users Fail: A Cross-Domain Benchmark of LLM-Simulated Human Survey Responses
*Source: tavily | 2026-09-09*

Large-scale benchmark across domains and model families shows LLM synthetic users fail to beat non-LLM baselines at the individual level and systematically over-weight demographic signals. This directly informs how we should (or should not) construct behavioral traits in our persona definitions.
**Tags:** `synthetic-data` `persona-simulation` `benchmarks`
**Prioridad:** 🔴 Alta

### How well do agents use test/verification techniques?
*Source: hackernews | 2026-09-08*

Dan Luu’s post and the ensuing discussion examine whether current agents can apply systematic verification or testing techniques when using tools. Several commenters note that most agents skip verification steps that would catch hallucinations or incorrect tool outputs—failure modes our Test Framework already flags.
