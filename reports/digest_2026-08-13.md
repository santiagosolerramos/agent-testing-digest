# Agent Eval Digest — 2026-08-13

## TL;DR
Sierra launched τ³-Bench, a new agent evaluation suite covering knowledge retrieval and voice—directly relevant for competitive benchmarking. A customer-service-specific eval framework emphasizes end-to-end resolution accuracy over deflection metrics. A practical guide on synthetic users clarifies their strengths for edge-case stress testing and their failure modes, giving concrete guardrails for our Test Framework personas.

## 🎯 Top 3 para Connectly

### 1. [Blog | Sierra](https://sierra.ai/blog?page=5)
**Por qué importa para Connectly:** Sierra (direct competitor) is shipping τ³-Bench for knowledge retrieval and voice evaluation, which overlaps with our multi-turn WhatsApp agents that must handle ambiguous goals and tool calls.  
**Acción concreta:** Add τ³-Bench-style knowledge-retrieval and voice test cases to the Test Framework YAML so we can run apples-to-apples regression checks against Sierra.

### 2. [AI Agent Evaluation Framework for Customer Service](https://fin.ai/learn/how-to-evaluate-ai-agents-customer-service)
**Por qué importa para Connectly:** Defines resolution accuracy as the primary metric for customer-service agents—the exact outcome our evaluations already try to measure after multi-turn conversations.  
**Acción concreta:** Replace or augment the current binary “correct outcome” check in Test Framework with a graded resolution-accuracy scorer that also flags unnecessary human handoffs.

### 3. [Synthetic Users: What AI Research Personas Can and Cannot Do](https://www.stackmatix.com/blog/synthetic-users)
**Por qué importa para Connectly:** Explicitly lists “stress-testing edge cases” as one of the three defensible uses of synthetic personas while warning about agreeable-mode collapse—exactly the risk we face when our personas only follow happy paths.  
**Acción concreta:** Update persona generation guidelines in Test Framework to force disagreement, fabrication attempts, and language switches so we catch the failure modes the article flags.
