# Agent Eval Digest — 2026-06-01

## TL;DR
The standout item is FutureAGI’s 2026 agent eval guide, which centers trajectories/traces and ships 70+ ready EvalTemplates (including function calling and conversation resolution) — directly relevant to our Test Framework. A real-world marketplace compromise (ClawHavoc) highlights supply-chain risks for agent skills. A production ranking of agent frameworks provides competitive context but little new eval methodology.

## 🎯 Top 3 para Connectly

### 1. [The Definitive Guide to AI Agent Evaluation (2026)](https://futureagi.com/blog/definitive-guide-ai-agent-evaluation-2026)
**Por qué importa para Connectly:** The guide treats the full trace (not single responses) as the unit of evaluation and supplies ready-made templates for exactly the checks we run in Test Framework (LLMFunctionCalling, TaskCompletion, ConversationResolution, Groundedness).
**Acción concreta:** Evaluate the open-source ai-evaluation SDK and map our existing persona YAML test cases to the ConversationCoherence / ConversationResolution templates.

### 2. [ClawHavoc Exposed: How 824 Malicious LLM Skills Infected the OpenClaw Marketplace](https://dev.to/olivier-coreprose/clawhavoc-exposed-how-824-malicious-llm-skills-infected-the-openclaw-marketplace-2di1)
**Por qué importa para Connectly:** Demonstrates how a single compromised marketplace of agent “skills” can inject malicious behavior into production conversational agents.
**Acción concreta:** Add a regression test that scans any third-party tools or skills we import for unexpected function-call patterns before they reach the Test Framework suite.

### 3. [AI Agent Frameworks 2026: Production-Tested Ranking](https://alicelabs.ai/en/insights/best-ai-agent-frameworks-2026)
**Por qué importa para Connectly:** Lists the seven frameworks actually used in 18+ production deployments (LangGraph, Claude Agent SDK, etc.), giving us a shortlist if we ever need to swap the underlying agent runtime.
**Acción concreta:** Run a quick bake-off of LangGraph vs. our current stack using the same persona set to quantify regression risk on tool-use and multi-turn coherence.

### Evaluation Frameworks & Benchmarks
### [The Definitive Guide to AI Agent Evaluation (2026)](https://futureagi.com/blog/definitive-guide-ai-agent-evaluation-2026)
*Source: tavily | 2026-06-01*

Emphasizes that agent evaluation must operate on full trajectories with spans rather than isolated responses, and releases an Apache-2.0 SDK containing 70+ EvalTemplate classes covering function calling, task completion, conversation coherence, resolution, groundedness, and context adherence. The approach maps almost 1:1 to Connectly’s Test Framework needs for deterministic multi-turn persona tests and tool-use verification.
