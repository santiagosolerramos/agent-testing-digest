# Agent Eval Digest — 2026-09-15

## TL;DR
Sierra and Arize both released concrete guidance on scaling agent evaluations and regression testing today. Sierra emphasizes synthetic benchmarks (τ-Bench) plus real-world simulations for enterprise agents; Arize shows how to run side-by-side experiment traces to catch prompt/model regressions before release. These map directly to Connectly’s open questions on persona quality, regression suites, and avoiding false positives in the Test Framework.

## 🎯 Top 3 para Connectly

### 1. [From LLMs to enterprise-grade agents | Sierra](https://sierra.ai/blog/enterprise-grade-agents)
**Por qué importa para Connectly:** Sierra (direct competitor) details their use of both real-world and synthetic evaluations (including τ-Bench) plus pre-deployment simulations to handle policy, empathy, and edge cases—exactly the gap our current Test Framework personas need to close.
**Acción concreta:** Add a τ-Bench-style synthetic scenario generator to the Test Framework YAML so every persona run includes policy-violation and multi-turn ambiguity checks before merging prompt changes.

### 2. [AI agent regression testing with Agent Experiments in Arize AX](https://arize.com/blog/ai-agent-regression-testing-with-arize-ax)
**Por qué importa para Connectly:** Arize’s experiment workflow lets teams replay the exact same dataset across current vs. proposed agent configs and diff traces + eval scores—directly solving our “catch subtle regressions when you update a prompt” problem.
**Acción concreta:** Prototype an Arize-style experiment runner that feeds our existing persona set into both the live agent and a candidate version, then surfaces only the turns where tool calls or handoff decisions changed.

### 3. [Top 8 WhatsApp AI agents for customer service in 2026 | Visito](https://www.visitoai.com/blog/top-8-whatsapp-ai-agents-to-automate-customer-service)
**Por qué importa para Connectly:** The post lists current WhatsApp agent capabilities (CRM actions, payment links, appointment changes) and positions them as production alternatives, giving us a quick competitive snapshot of feature parity.
**Acción concreta:** Run a one-time audit of the eight named platforms against our current tool-use coverage to identify any missing WhatsApp-specific actions we should add to the mock catalog.
