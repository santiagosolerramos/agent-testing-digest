# Agent Eval Digest — 2026-10-20

## TL;DR
Sierra launched Agent Studio with built-in conversation simulation and regression testing, directly relevant to Connectly's Test Framework. EvalView's breakdown of what to regression-test (tool paths, turn sequences, silent failures) gives concrete criteria we can adopt. Laminar's error-finding model on agent traces offers a potential way to automate detection of subtle prompt regressions.

## 🎯 Top 3 para Connectly

### 1. [Agent Studio | Sierra](http://www.sierra.ai/product/agent-studio)
**Por qué importa para Connectly:** Sierra (direct competitor) now offers exactly the conversation simulation + regression suite our Test Framework needs for multi-turn WhatsApp agents.
**Acción concreta:** Map their "simulate conversations against defined outcomes" feature against our current persona YAML and add a regression gate before any prompt release.

### 2. [AI Agent Regression Testing | EvalView](https://evalview.com/ai-agent-regression-testing)
**Por qué importa para Connectly:** Explicitly calls out testing tool-use sequences and silent 200-OK failures, which matches one of our open questions on catching regressions beyond text quality.
**Acción concreta:** Extend our evaluation step to assert on tool call order and latency/cost in addition to final outcome.

### 3. [Launch HN: Laminar (YC S24) – RL-trained model that finds errors in agent traces](https://news.ycombinator.com/item?id=50154029)
**Por qué importa para Connectly:** An RL model specialized at spotting errors in full agent traces could reduce false positives in our large-scale persona runs.
**Acción concreta:** Prototype Laminar (or similar) as an additional evaluator layer on top of our existing Test Framework outcomes.
