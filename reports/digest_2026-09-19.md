# Agent Eval Digest — 2026-09-19

## TL;DR
Two new WhatsApp-native sales agents (Dealism and Kipps AI) launched today, giving direct competitive visibility into how others handle multi-turn qualification and lead handling on the same channel Connectly uses. A new practical guide on regression testing for agents emphasizes trajectory and side-effect checks, which maps straight onto Test Framework gaps around prompt changes and false positives.

### 1. [Dealism: WhatsApp AI Sales Agent & Lead Qualifier](https://thetoolsverse.com/tools/dealism-whatsapp-ai-sales-agent)

**Acción concreta:** Extend the Test Framework evaluation step to include trajectory logging and side-effect assertions so we can gate releases on more than text quality.

### 3. [Kipps AI WhatsApp Agent Review | Kipps AI WhatsApp Agent | Stork.AI](https://www.stork.ai/en/kipps-ai-whatsapp-agent)
