# Agent Eval Digest — 2026-07-04

## TL;DR
Offline + online evaluation split and trajectory scoring frameworks are maturing fast; Sierra’s new Agent OS directly competes on multi-channel customer agents; drift detection and trace sampling techniques now offer concrete ways to reduce false positives in regression suites. These directly address Connectly’s open questions on scaling evals, catching subtle prompt regressions, and building a deterministic Test Framework.

## 🎯 Top 3 para Connectly

### 1. [AI Agent Evaluation (2026): The Metrics, the Frameworks, and Why ...](https://www.morphllm.com/ai-agent-evaluation)
**Por qué importa para Connectly:** Explicitly recommends running offline evals against fixed task datasets in CI (exactly like our Test Framework) while layering online monitoring for drift and jailbreaks on production WhatsApp traffic.  
**Acción concreta:** Adopt the offline-vs-online split as the default structure for our persona YAML tests and add a lightweight online drift check on a sample of live conversations.

### 2. [Agents as a service - Sierra AI](https://sierra.ai/blog/agents-as-a-service)
**Por qué importa para Connectly:** Sierra’s Agent OS 2.0 and Agent Data Platform target the same multi-channel, memory-driven customer support use case we serve on WhatsApp; their new tooling is a direct competitive benchmark.  
**Acción concreta:** Evaluate whether Sierra’s Agent Studio 2.0 persona and memory features expose evaluation gaps we should close in our own Test Framework.

### 3. [Evals for Agents: Scoring Task Success, Trajectory, and Human Review](https://dev.to/gabrielanhaia/evals-for-agents-scoring-task-success-trajectory-and-human-review-31jj)
**Por qué importa para Connectly:** Shows concrete ways to score full trajectories (tool calls + final outcome) plus lightweight human review—directly applicable to our multi-turn goal-oriented test cases.  
**Acción concreta:** Extend our current evaluation step to include trajectory-level scoring in addition to the existing outcome checks.
