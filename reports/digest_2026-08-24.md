# Agent Eval Digest — 2026-08-24

## TL;DR
Two directly actionable pieces landed today: a production-focused LLM evaluation checklist that stresses testing the full application stack (retrieval, tools, safety) rather than model benchmarks, and a concrete regression-testing loop that mines production failures to build behavior datasets. Both map cleanly to Connectly’s Test Framework and open questions around regression suites and catching subtle prompt/model regressions.

## 🎯 Top 3 para Connectly

### 1. [LLM Evaluation Checklist 2026: 10 Tests to Run Before Your AI Goes to Production](https://dev.to/quokkalabs/10-tests-to-run-llm-evaluation-checklist-5e13)
**Por qué importa para Connectly:** It explicitly calls out the need to test the full application (retrieval, tool use, boundary crossing) instead of isolated model scores — exactly the gap our Test Framework tries to close with persona-driven multi-turn runs.
**Acción concreta:** Map the 10-test checklist against our current evaluation criteria and add any missing checks (especially tool-use and safety boundary tests) to the YAML test-case schema.

### 2. [AI Agent Regression Testing From Production Failures | Arthur](https://www.arthur.ai/column/regression-test-datasets-ai-agents-production-failures)
**Por qué importa para Connectly:** Describes a closed loop that turns continuous-eval failures into a reusable behavior dataset — directly relevant to our open question on building a regression suite that catches regressions after prompt or model changes.
**Acción concreta:** Prototype ingesting failed Test Framework runs (with expected outputs) into a “behavior dataset” that must pass before any prompt/model promotion.

### 3. [AI Agents and Tool Use](https://dev.to/godofgeeks/ai-agents-and-tool-use-3iii)
**Por qué importa para Connectly:** While mostly high-level, it highlights the difficulty of evaluating tool selection and chaining in multi-turn flows — an area where our personas could be extended.
**Acción concreta:** Review whether our current persona objectives already cover tool-use edge cases; if not, add 3–5 new objectives focused on tool misfires.

### Regression Testing & CI/CD for Agents

### [AI Agent Regression Testing From Production Failures | Arthur](https://www.arthur.ai/column/regression-test-datasets-ai-agents-production-failures)
*Source: tavily | 2026-08-24*

Describes a practical loop: monitor continuous eval failures, add them to a behavior dataset with expected outputs, iterate until the dataset passes, and only then promote changes. The same dataset serves as both training signal and regression guard. This is immediately usable by Connectly to turn failed persona runs into a permanent regression suite.
