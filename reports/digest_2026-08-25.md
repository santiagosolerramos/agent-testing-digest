# Agent Eval Digest — 2026-08-25

## TL;DR
The standout item is a new benchmark showing LLM synthetic users systematically fail at individual-level simulation and over-rely on demographic stereotypes—directly relevant to Connectly's persona-driven Test Framework. Generic LLM eval frameworks and a new inference-engine security paper round out today's findings, but only the synthetic-user work has immediate implications for reducing false positives in multi-turn WhatsApp agent tests.

## 🎯 Top 3 para Connectly

### 1. [When Synthetic Users Fail: A Cross-Domain Benchmark of LLM-Simulated Human Survey Responses](https://arxiv.org/html/2607.26348)
**Por qué importa para Connectly:** Directly demonstrates why current demographic-prompted personas will produce brittle test cases in the Test Framework, especially on cross-cultural or value-laden conversations.  
**Acción concreta:** Add a "demographic leakage" check to the evaluation suite and require personas to be validated against real conversation logs rather than static attributes.

### 2. [Evaluation Frameworks for LLMs](https://dev.to/godofgeeks/evaluation-frameworks-for-llms-106)
**Por qué importa para Connectly:** Surveys practical LLM eval stacks that could be adapted to measure multi-turn goal completion instead of just text quality.  
**Acción concreta:** Prototype one of the non-LLM baselines mentioned (e.g., human-response matching) as an additional scorer in the Test Framework YAML.

### 3. [Can an LLM Take Over the Machine That's Running It?](https://dev.to/vin-patel/can-an-llm-take-over-the-machine-thats-running-it-nin)
**Por qué importa para Connectly:** Highlights a new attack surface in inference engines that could affect any production agent handling customer data on WhatsApp.  
**Acción concreta:** Add a lightweight red-team test case that probes whether the agent can be tricked into leaking mock order data via inference-engine side channels.

## Top Findings

### Synthetic User & Persona Simulation

### [When Synthetic Users Fail: A Cross-Domain Benchmark of LLM-Simulated Human Survey Responses](https://arxiv.org/html/2607.26348)
*Source: tavily | 2026-08-25*

Across two domains and multiple models, LLM-simulated users underperform non-LLM baselines at the individual level and systematically treat demographics as overly predictive of attitudes. This directly challenges the current persona design in Connectly's Test Framework, which relies on name + goal + behavioral traits. The work suggests we need stronger validation against real conversation distributions rather than synthetic demographic prompting.
