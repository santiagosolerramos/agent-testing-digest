### Evaluation Frameworks & Benchmarks

### [Open Models have crossed a threshold](https://blog.langchain.com/open-models-have-crossed-a-threshold/)
*Source: LangChain Blog | 2026-04-02*

This blog post from LangChain highlights how open models like GLM-5 and MiniMax M2.7 are now performing on par with closed frontier models in agent-specific tasks such as file operations, tool use, and instruction following, backed by their internal evals that show significant cost and latency reductions. What's novel is the practical demonstration that these models can be swapped in for real-world applications without sacrificing quality, making them ideal for scalable testing environments. For Connectly, this means we could incorporate these models into our Test Framework to run faster, cheaper simulations of synthetic personas in WhatsApp scenarios, directly addressing our open question on scaling evals without false positives by using deterministic mock data with lower overhead.

### [pydantic/pydantic-ai v1.74.0](https://github.com/pydantic/pydantic-ai/releases/tag/v1.74.0)
*Source: GitHub | 2026-03-31*

This GitHub release for pydantic-ai introduces features like an online evaluation infrastructure and enhanced handling of user prompts with metadata, allowing for more structured and automated testing of AI outputs. What's interesting is the addition of tools for evaluating model responses in real-time, which could help in building robust regression suites by integrating metadata that doesn't get sent to the model, reducing noise in evaluations. For Connectly, this translates to potentially upgrading our Test Framework to use these features for better tracking of agent tool calls and conversation outcomes in multi-turn WhatsApp tests, making it easier to catch subtle regressions when updating prompts or models while maintaining our persona-based objectives.
