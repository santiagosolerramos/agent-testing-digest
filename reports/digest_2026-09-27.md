# Agent Eval Digest — 2026-09-27

## TL;DR
Three items today focus on the limitations and practical use of synthetic users for UX and product testing. The most relevant signal is that LLM-driven personas tend to be overly agreeable and miss the critical "flinch" reactions that surface real edge cases—directly applicable to improving Connectly's Test Framework personas.

## 🎯 Top 3 para Connectly

### 1. [Synthetic Users Are Too Agreeable for Real UX Testing](https://pipelinemag.ai/posts/synthetic-users-too-agreeable-ux-testing)
**Por qué importa para Connectly:** Directly highlights why current synthetic personas fail to surface the ambiguity and objection behaviors that WhatsApp users exhibit in cart recovery or order cancellation flows.
**Acción concreta:** Update the persona YAML in Test Framework to inject explicit "disagreeable" or skeptical traits and re-run the existing regression suite to measure delta in failure detection.

### 2. [The Infinite Feedback Loop: Synthetic Users & Product Testing](https://productleadersdayindia.org/blogs/agentic-ai-product-management/synthetic-users-product-testing.html)
**Por qué importa para Connectly:** Describes moving from static personas to dynamic, reasoning agents that can iterate on multi-turn conversations—exactly the gap between our current test cases and real WhatsApp goal-oriented dialogues.
**Acción concreta:** Prototype a "persona matrix" generator that creates 5–10 variants per objective (e.g., cancel order) with different reasoning styles and integrate it into the nightly eval pipeline.

### 3. [Automated UI Testing with Synthetic Users](https://huntscreens.com/products/synthetic-users)
**Por qué importa para Connectly:** Shows a working pattern for generating tests from prompts and adapting to UI changes inside CI/CD—relevant for catching regressions after prompt or tool-calling updates.
**Acción concreta:** Evaluate whether the same "generate tests from prompt + adapt to changes" loop can be applied to our conversation transcripts instead of UI screenshots.
