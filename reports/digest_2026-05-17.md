# Agent Eval Digest — 2026-05-17

## TL;DR
Two new resources stand out today for conversational agent testing: an open-source tool (Sensei) that generates full multi-turn conversations against any REST-accessible agent, and practical guidance on end-to-end dialogue validation that explicitly covers messaging channels. Both map directly to Connectly’s Test Framework needs around deterministic persona simulation, multi-turn outcome checking, and handoff scenarios.

### [PDF] Automated End-to-End Testing for Conversational Agents - miso
*Source: tavily | 2026-05-17*

Sensei is an open tool that synthesizes full conversations from persona-like user goals and executes them against any agent reachable via REST API; the authors also apply mutation testing to measure the effectiveness of the generated test cases. This is one of the closest published implementations to Connectly’s internal Test Framework and offers a ready reference for improving persona generation and outcome verification. The mutation-testing results provide a concrete method to answer “how do you write personas that find real edge cases.”

### Conversational AI Testing: End-to-End Validation for Dialogue Systems
*Source: tavily | 2026-05-17*

The article breaks down practical end-to-end checks for messaging agents, including response-length appropriateness, conversation-completion patterns, rate limiting, and escalation/handoff scenarios. These dimensions map almost one-to-one to WhatsApp agent behavior and give us ready-made evaluation criteria beyond simple text quality. The FAQ section also clarifies how to scope “conversational AI testing” for goal-oriented, multi-turn flows.
